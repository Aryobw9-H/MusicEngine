# Tricky Finglish → Persian — MusicEngine curated override layer.
#
# Words the naive per-letter tables get wrong on colloquial Persian (محاوره):
#   • mi- verb prefix (mikham = میخوام — NOT میخام)
#   • -e/-eh word-final (mishe = میشه, not میشع)
#   • dropped letters in song-speak (vaseh/vase = واسه, baraye = برای)
#   • kh/gh/t-h clusters (dokhtar = دختر, ashegh = عاشق)
#   • long-vowel words (akhbar tables drop ā: jahan→جهن, parvaz→پروز)
# These are the words that ACTUALLY appear in Iranian song titles and chats.
# Format: `<finglish> <persian>` — same as f2p-dict.txt; checked FIRST.
